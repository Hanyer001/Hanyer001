# Hi, I'm Hanyer

I build applications that combine practical interfaces with backend and systems programming. My public work includes a music player for Windows and Android, a browser-based reading library, interactive web prototypes and academic projects in Rust, graph analysis and computer vision.

## Selected projects

| Project | What to explore | Technologies |
| --- | --- | --- |
| **[Antares](https://github.com/Hanyer001/Antares)** | Music playback, smart playlists, listening-based discovery and native platform integration. Windows release and Android beta available. | Tauri 2, Rust, JavaScript, Kotlin, Media3 |
| **[Lector Manga](https://github.com/Hanyer001/lector_manga)** | Multi-source library, vertical/paginated reading, progress synchronization and an encrypted private vault. | Node.js, Express, JavaScript, SQLite, Supabase, Playwright |
| **[Research Collaboration Portal](https://github.com/Hanyer001/Pagina_cliente)** | Searchable researcher profiles, project views and interactive collaboration graphs using fictional data. | JavaScript, Bootstrap, vis-network |
| **[OS Architecture Simulations](https://github.com/Hanyer001/Tarea_Sistemas)** | Layered architecture and microkernel message passing, with console traces and a comparative report. Team coursework. | Rust, Cargo |
| **[Music Artist Communities](https://github.com/Hanyer001/Entrega-3-Redes)** | Genre-similarity graphs and a comparison of Girvan–Newman and Louvain communities. | Python, pandas, NetworkX |
| **[Construction Safety Detection](https://github.com/Hanyer001/Proyecto-de-Procesamiento-de-Im-genes-Digitales-y-Visi-n-por-Computador)** | An exploratory notebook comparing object detectors and vision-language models, including results and limitations. | Python, YOLO, PyTorch, Transformers |

## Start here

- **Desktop and mobile development:** [Antares source](https://github.com/Hanyer001/Antares), [website](https://hanyer001.github.io/Pagina-Antares/) and [release packages](https://github.com/Hanyer001/antares-actualizaciones/releases).
- **Full-stack web development:** [Lector Manga](https://github.com/Hanyer001/lector_manga), including a local reader demo and API, storage and browser tests.
- **Frontend interaction design:** [Research Collaboration Portal](https://github.com/Hanyer001/Pagina_cliente) and the [Antares website source](https://github.com/Hanyer001/Pagina-Antares).

The project READMEs describe setup, architecture and current limitations. Antares and Lector Manga also include a Spanish README. Several application interfaces and academic reports are in Spanish.
